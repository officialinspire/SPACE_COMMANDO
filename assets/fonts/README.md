# Fonts

**Barlow Condensed** SemiBold (600) and Bold (700), Latin subset, by The Barlow Project Authors (https://github.com/jpt/barlow), from the `@fontsource/barlow-condensed` 5.1.0 package. It's licensed under the SIL Open Font License 1.1; the full text is in [OFL.txt](OFL.txt).

It's used for display text only: titles, headings, labels and the stage banner. Body copy and button labels use the system UI font for legibility.
